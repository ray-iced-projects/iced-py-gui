Creating a Checkbox Palette

-----------
Definition:
-----------

Many widgets have various statuses like, active, hovered, pressed, is_checked, etc.  Internally, the Iced gui sets a different color of the widget based on the status which allows one to see that the widget is active, hovered, etc.  The Iced gui also has a unique palette for each color theme, like Dark, Light, ...

If one sets the color of a widget using the add_{widget name}_style(bkg_color=Color.Blue), as the status of the widget changes, the assigned color will not change.

However, if one creates a custom palette for the widget, then as the status changes, the color will change accordingly to how the custom palette is defined.

As with the Iced themes, you can create a custom palette for each theme or, for example, create a custom palette for dark and light colors that looks right to you for all of the themes.

Icedpygui allows any combination of your choosing and also allows one to create custom palettes that extend the changes beyond what Iced does.  For example, the border colors are usually not included in Iced palettes but for ipg, you can include them, if so desired.

Therefore, any part of a widget that can be assigned to a color can change according to the status, if so desired.

---------------------------------
Palette Creation for the Checkbox:
---------------------------------

When creating a palette for the checkbox, you can only use the StyleParts, Background, Border, Icon and Text.  The other StyleParts you see on the hint list, belong to other widgets with overlap.  You don't need to use all 4 parts but it's advisable to use all statuses for each part.

The Border will only show when the border width > 0. So if you want to use a border, in the add_checkbox_style() set the border to something > 0.

-------------------------------------------
Steps to define a palette for the Checkbox:
-------------------------------------------

*** Step 1:  Create the custom palette:

Create the statuses using the format below (scroll to see).  This format is used for all widgets for the custom palette.  The entries will be different based on what statuses a widget will use, StylePart, and PaletteKey.

The palettes can be stored in a .yml file and loaded as in this example or stored directly in the program.

The PaletteKeys are Base, Neutral, Strong, Stronger, Strongest, Weak, Weaker, Weakest, along with the Text versions, i.e. BaseText, etc.

For the PaletteKeys, with the Text term, are colors calculated to be contrasting to the palette color.  If those don't match what you like, you can use the alpha value to blend it with the background. 

The StyleParts for a checkbox are just the 4 indicated below.  Other widgets will have similar ones.  When you see the StylePart hint list, it will contain all of the parts for all of the widgets.  Use the ones for your widget of interest only.

Since the checkbox has two StateVariants, it doubles in size since one uses both the checked and unchecked variants.  

***The palette format***

pal = [
    ((WidgetStatus.Active, StateVariant.Unchecked), (
                            (StylePart.Border,      PaletteKey.Strong,   1.0),
                            (StylePart.Background,  PaletteKey.Base,     1.0),
                            (StylePart.Text,        PaletteKey.BaseText, 0.8),
                            ),
    ),
    ((WidgetStatus.Hovered, StateVariant.Unchecked), (
                            (StylePart.Border,      PaletteKey.Strong,   1.0),
                            (StylePart.Background,  PaletteKey.Weak,     1.0),
                            (StylePart.Text,        PaletteKey.BaseText, 0.8),
                            ),
    ),
    ((WidgetStatus.Disabled, StateVariant.Unchecked), (
                            (StylePart.Border,      PaletteKey.Strong,   1.0),
                            (StylePart.Background,  PaletteKey.Weaker,   1.0),
                            (StylePart.Text,        PaletteKey.BaseText, 0.8),
                            ),
    ),
    ((WidgetStatus.Active, StateVariant.Checked), (
                            (StylePart.Border,      PaletteKey.Strong,   1.0),
                            (StylePart.Background,  PaletteKey.Base,     1.0),
                            (StylePart.Icon,        PaletteKey.BaseText, 1.0),
                            (StylePart.Text,        PaletteKey.BaseText, 0.8),
                            ),
    ),
    ((WidgetStatus.Hovered, StateVariant.Checked), (
                            (StylePart.Border,      PaletteKey.Strong,   1.0),
                            (StylePart.Background,  PaletteKey.Strong,   1.0),
                            (StylePart.Icon,        PaletteKey.BaseText, 1.0),
                            (StylePart.Text,        PaletteKey.BaseText, 0.8),
                            ),
    ),
    ((WidgetStatus.Disabled, StateVariant.Checked), (
                            (StylePart.Border,      PaletteKey.Strong,   1.0),
                            (StylePart.Background,  PaletteKey.Weak,     1.0),
                            (StylePart.Icon,        PaletteKey.BaseText, 1.0),
                            (StylePart.Text,        PaletteKey.BaseText, 0.8),
                            ),
    ),
]

*** Step 2: Create a new color and then obtain the custom_palette().  The pal_id would be added to the parameter palette_id.  The color can be obtained by using the ColorPicker widget, if you want, or just supply the list of 4 float values.

Example:

new_color = [0.32, 0.2, 0.13, 1.0]
pal_id = custom_palette(rgba=new_color, statuses=pal) # pal as defined above

Incorporate the palette_id:

add_checkbox(label="Checkbox", palette_id=pal_id)
