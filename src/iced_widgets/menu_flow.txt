Menu
└── MenuBar (top-level items like "File", "Edit")
    └── MenuItem (dropdown items)
        ├── Content widgets (Row, Text, Checkbox, etc.)
        └── Optional: SubMenu (nested)
            └── MenuItem (recursive pattern)
                ├── Content widgets
                └── Optional: SubMenu (and pattern repeats)


collect_menu_item_content() {
  - Collects content widgets from MenuItem
  - If SubMenu exists:
    - Calls collect_sub_items() to get submenu items
    - Returns GroupedItem::Sub with trigger (content) + children (submenu items)
  - Else: Returns GroupedItem::Plain with content
}

collect_sub_items() {
  - Iterates SubMenu's MenuItem children
  - For each MenuItem:
    - Calls collect_menu_item_content() recursively
    - This allows nested SubMenus within SubMenus
}
